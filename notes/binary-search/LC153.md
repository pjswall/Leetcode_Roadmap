# LC 153 — Find Minimum in Rotated Sorted Array

**Current checkpoint:** Binary Search Level 3, Problem 2 — Learning.

## Recognition
A sorted array is rotated; use comparisons to eliminate half of the search interval rather than scanning linearly.

## Key invariant
The minimum is somewhere within the current inclusive range `[left, right]`.

For distinct elements, compare `nums[mid]` with `nums[right]`:
- If `nums[mid] > nums[right]`, the minimum must be strictly right of `mid`.
- Otherwise, the minimum is within `[left, mid]` and **mid must be retained**, because it could itself be the minimum.

## Complexity target
Time `O(log n)`, extra space `O(1)`.

## Test inputs
`[3,4,5,1,2]`, `[4,5,6,7,0,1,2]`, `[11,13,15,17]`, `[1]`.

## Common mistake
Setting `right = mid - 1` in the second case can discard the actual minimum.
