# LC 930 — Binary Subarrays With Sum

**Status:** Learning; independent acceptance not confirmed.

## Recognition
The question asks for the number of subarrays with **exactly** a target sum in a binary array.

## Two solution patterns

1. **At-most counting:** `exactly(goal) = atMost(goal) - atMost(goal - 1)`. For a valid window ending at `right`, count `right - left + 1` possible starts. Shrink only when the window sum exceeds the threshold. If the threshold is negative, return zero.
2. **Prefix sums + frequency map:** at current prefix `p`, the required earlier prefix equals `p - goal`. Add the occurrence count from a map before recording current `p`. Initialize the map with `{0: 1}` to account for subarrays starting at index zero.

## Watch out for
- Sliding-window at-most counting relies on nonnegative array entries.
- Subtracting counts is different from trying to count exact windows directly with a simple shrink rule.
- Prefix value `1` can occur multiple times, so frequencies matter, not just membership.
