## Quick recognition
- **Exactly k contiguous elements:** fixed-size.
- **Longest/shortest range respecting constraint:** variable-size.
- **Anagrams/permutations:** frequency matching.
- **Smallest containing all required chars:** minimum valid window.
- **Count exact K:** at-most subtraction where monotonicity applies, otherwise prefix map.
- **Moving extreme or shortest sum with negatives:** monotonic deque / prefix sums.
